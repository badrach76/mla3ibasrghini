# منصة ملاعب السرغيني — نسخة أولية

## المحتويات
- `index.html`: واجهة عربية RTL متجاوبة مع الهاتف.
- `mla3ibasrghini.jpg`: الشعار المرفق/المتاح في مساحة العمل، محفوظ بالاسم المطلوب.
- `supabase_schema.sql`: مخطط أولي للجداول المقترحة في Supabase.

## المعاينة
افتح `index.html` في المتصفح. يمكن تجربة إرسال طلبات الحجز والانخراط ومراجعتها من لوحة الإدارة التجريبية. البيانات تحفظ في `localStorage` على الجهاز نفسه فقط.

## حدود هذه النسخة
هذه **واجهة نموذج أولي وليست منصة منشورة أو نظام إنتاج آمنًا**. لا يوجد ربط فعلي بـ Supabase أو Vercel، ولا تسجيل دخول حقيقي أو دفع إلكتروني أو إشعارات واتساب. لوحة الإدارة التجريبية غير محمية، لذلك لا تدخل بيانات شخصية حقيقية.

## النشر وربط قاعدة البيانات
1. أنشئ مشروع Supabase.
2. راجع `supabase_schema.sql` وشغّله بعد تكييفه.
3. أضف سياسات Row Level Security دقيقة وأدوار المصادقة؛ لا تفتح بيانات الهواتف للعامة.
4. استبدل التخزين المحلي بعمليات Supabase، واجعل إنشاء/تأكيد الحجز عملية ذرية تمنع تداخل الأوقات في قاعدة البيانات.
5. ارفع الملفات إلى مستودع GitHub ثم اربط المستودع بـ Vercel.
6. اختبر صلاحيات الإدارة والمنخرطين والحجوزات المتزامنة قبل الإطلاق.

## قواعد تشغيل مقترحة تحتاج موافقة الإدارة
- فتح الحجز المبكر للمنخرطين.
- حد أقصى للحجوزات المتزامنة لكل فريق.
- مهلة تأكيد الحجز والعربون.
- سياسة الإلغاء والتغيب والاسترداد.
- تحديد الأسعار ومدة الفترات لكل ملعب.
